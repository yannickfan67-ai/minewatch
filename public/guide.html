How it works

1. A player explicitly starts sharing. The Cloudflare Worker allocates a Camera ID.

2. A Durable Object carries WebRTC signaling and chat messages. It does not carry normal video traffic.

3. Each viewer creates a WebRTC peer connection to the broadcaster. STUN is used for NAT discovery. TURN can relay when direct connectivity fails.

4. Direct mode costs little server bandwidth but the broadcaster upload grows with viewer count. This build caps each camera at 8 viewers.

5. Relay-only mode prevents direct peer-to-peer network exposure but consumes TURN bandwidth.

Minecraft integration

The included browser publisher is a reference implementation. A Fabric client mod can implement the same signaling protocol and publish Minecraft frames through an embedded WebRTC library. Keep a permanent LIVE indicator in-game and require the player to start every session explicitly.
