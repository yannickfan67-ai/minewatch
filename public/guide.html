Guide

If you're reading this, you're probably new here.

This guide contains the essential information needed to use MineWatch.

The navigation bar at the top links to the main parts of the website. Open Cameras to see the available camera feeds.

Each camera tile has an ID underneath it. Select a tile to open the feed, or use Random camera if you don't want to choose one yourself.

A camera page shows its title, ID, runtime, feed and chat area. A multiplayer feed may have chat activity while a singleplayer feed normally does not.

In this recreation, camera sharing is voluntary. The player starts the sharing client themselves and can stop it at any time.
